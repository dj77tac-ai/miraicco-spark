# Spark 電子ブック

みらいっこの月刊誌 **Spark** の PDF を、保護者がスマートフォンやパソコンで
「ページをめくるように」読めるようにする仕組み。

有料サービス（FlipBuilder・年 $99）の代わりに作ったもの。
**費用はかからず、支払いが止まって突然読めなくなることもない。**

---

## 何をしているのか（しくみ）

1. PDF を1ページずつ画像に変える
2. その画像を**合言葉で暗号化**して `docs/d/` に置く
3. 置き場所（GitHub Pages など）は誰でもアクセスできるが、
   ファイルの中身は合言葉なしでは**ただの意味のないデータ**にしか見えない
4. 保護者が合言葉を入れると、**そのブラウザの中だけで**画像に戻して表示する

サーバー側に仕掛けが要らないため、無料の置き場所だけで動く。

### 大事なこと

- **合言葉は暗号化そのものに使われている。** 画面をごまかして通り抜ける、
  ということができない作りになっている
- ただし、暗号化されたファイル自体は誰でも手に入る。
  **合言葉が短かったり、よくある単語だったりすると、時間をかければ破られる。**
  12文字以上・辞書に無い言葉を混ぜたものにすること
- 合言葉を変えたら**全部作り直し**（`node build.mjs` をやり直す）になる

---

## ファイルの置き場所

| 場所 | 中身 |
| --- | --- |
| `config.json` | 号の一覧（号の名前・元の PDF のファイル名） |
| `password.txt` | 合言葉。**git に入らない**（`.gitignore` 済み） |
| `build.mjs` | PDF → 画像 → 暗号化 をする道具 |
| `docs/` | **これを公開する。** 画面のプログラムと暗号化ずみのデータ |
| `docs/d/` | 暗号化された本文（`build.mjs` が作る） |
| `work/` | 変換の途中で使う場所。作業後に自動で消える |

> `docs` という名前なのは、GitHub Pages が「リポジトリ直下」か「docs フォルダ」しか
> 公開できないため。説明書ではなく**公開されるサイト本体**が入っている。

## 新しい号を出すとき

1. PDF を `config.json` の `pdfDir` のフォルダへ入れる
2. `config.json` の `issues` に1行足す

   ```json
   { "id": "202510", "label": "2025年10月号", "pdf": "C009_Spark202510.pdf" }
   ```

   - `id` は URL に使う名前（半角英数字）
   - `label` が一覧に出る名前
   - 並び順は上から古い順。新しい号は**いちばん下**に足す（一覧では新しい順に出る）

3. 作り直す

   ```bash
   cd "Spark電子ブック"
   node build.mjs
   ```

4. 公開する

   ```bash
   git add -A && git commit -m "2025年10月号を追加" && git push
   ```

   push すると1〜2分で反映される。

## 手元で見て確かめる

```bash
cd "Spark電子ブック/docs" && python3 -m http.server 8765
```

ブラウザで `http://localhost:8765` を開く。
（`file://` で直接開くと、ブラウザの決まりで暗号を戻せないため動かない）

## 必要なもの

- `pdftoppm` / `pdfinfo`（PDF を画像にする道具）
  ```bash
  brew install poppler
  ```
- Node.js（18 以上）

## 画面の作りかた

- `docs/index.html` … 3つの画面（合言葉／一覧／読む）
- `docs/app.js` … 合言葉の確認・暗号を戻す・ページめくり
- `docs/style.css` … 見た目
- `docs/vendor/page-flip.*` … ページめくりの部品（[page-flip](https://github.com/Nodlik/StPageFlip) 2.0.7・MIT ライセンス）

`app.js` や `style.css` を直したら `node build.mjs` を実行すること。
`index.html` の中の番号が付け替わり、保護者のブラウザが古いものを使い続けるのを防ぐ。

## 決めたこと・注意

- **画像は 150dpi・JPEG 品質 82。** A4 で1ページ約 400KB。
  もっときれいにしたい場合は `config.json` の `dpi` を上げる（そのぶん重くなる）
- **表紙は表紙だけで1ページ**として表示される（隣は白紙になる）。
  紙の雑誌と同じ見え方
- **合言葉は端末におぼえさせている**（`localStorage`）。
  一度入れれば次からは入れ直さなくてよい。「とじる」を押すと忘れる
- 検索に出ないよう `robots.txt` と `noindex` を入れてある
